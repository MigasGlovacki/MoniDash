# MoniDash

MoniDash é um mod Geode local para Geometry Dash 2.2081 que coleta telemetria
de sessões (tentativas, contexto de morte, eventos de gameplay e referências de
treino por start position) para análise posterior conduzida por um companheiro
de IA. O mod permanece offline; um relay separado sincroniza sessões finalizadas
para um hub privado.
